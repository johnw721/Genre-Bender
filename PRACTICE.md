# Genre Bender — daily practice checklists

Three sessions, 10–20 min each. Every step names the exact tab / button in the app.
Default: **B (Trainer-first)** daily · **A (Clip → chart)** twice a week · **C (Blend & play)** Saturdays.

Shared setup (every session, ~30 s)
- [ ] Open the app. Left rail: confirm **Current key** and the tempo keeper are showing.
- [ ] Rail header **▾** → expand the clip player if collapsed. Press **⇱** to float it if you want it over the trainer.
- [ ] Metronome: set swing preset to taste (neo-soul/gospel → swing on).

---

## A · Clip → chart (~15 min) — ear + transcription

**0–3 min · capture the reference**
- [ ] Copy a link (X / Instagram / TikTok / YouTube — full URL, not `vm.tiktok.com`), then Ctrl/Cmd+V anywhere on the page (or paste into the rail box → **Open**).
- [ ] Give the clip a **label**.
- [ ] Play the clip; **tap tempo** on the metronome along with it for 8+ beats, then press **↓ bpm** on the clip card to capture it.
- [ ] Set the key: rail **Current key** select. Not sure? → tab **03 — Analyze Track**, pick the clip, paste its caption / describe what you hear → **Analyze ↗** → accept the key/genre guess (write back to tags).
- [ ] Fill the clip's **genre** tags if Analyze didn't.

**3–10 min · build the progression**
- [ ] Inner tab **Shape trainer** → mode **My chords**.
- [ ] **+ track** → name it after the clip.
- [ ] Loop the clip in the floating player. For each chord you hear:
  - [ ] Type frets into the six fret squares (0 = open, x = muted) → watch the live chord / degree readout.
  - [ ] **+ add from frets** once the readout matches what you hear (or **+ add by name** if you already know it).
  - [ ] Colour wrong? Use the quality selector on the block (maj7 → 9 → 13 …). Clash with key? → **🔑 make in key**.
- [ ] Reorder with **◀ ▶** or drag the diagram to a new slot until the order matches the record.

**10–15 min · play it**
- [ ] Start the metronome at the captured BPM; play the track through 4× clean.
- [ ] For each gap between chords: **▶ play** the suggested fill → try it → **🔀 different lick** if it doesn't fit. Keep one fill per gap you can actually play.
- [ ] Drag the 2–3 voicings you liked from the track **down into the Chord table** so they're saved for later.
- [ ] Done. (Optional: trainer stats glance — anything due? Do 5 cards.)

## B · Trainer-first (~12 min) — SRS fluency (daily default)

**Rotation** — Mon Scale shapes · Tue Shape→Number · Wed Number→Shape · Thu Moving shapes · Fri Progression ID · Sat/Sun **Mixed** (or whichever mode stats show weakest).

**0–1 min**
- [ ] Open one saved clip in the rail (**docked**, not floating) so the reference is in your ear. Don't touch it again.
- [ ] Inner tab **Shape trainer** → pick today's mode.

**1–8 min · quiz (records progress)**
- [ ] Make sure the view is **quiz** (not **🧭 explore this drill**).
- [ ] Answer cards back-to-back. Number→Shape: type frets → **Enter** (or check-shape button). Progression ID: **▶ play** once, then answer.
- [ ] Don't stall — if you're stuck >15 s, **give up**, read the reveal, move on (it drops to box 0 and comes back this session).
- [ ] Target: 20–30 cards. Stop at 8 min regardless.

**8–12 min · explore (no progress recorded — pure play)**
- [ ] Press **🧭 explore this drill** for the same mode.
- [ ] Set the sandbox key to the open clip's key.
- [ ] Four minutes of free play: tap degree chips / move the barre shape / step the progression / pick a scale box, and watch the readout name what you're playing.
- [ ] Found a voicing you like? Switch to **My chords**, type its frets → **+ add to table**.

**Weekly (Sunday)**
- [ ] Trainer stats: note the weakest mode → that's next week's Sat/Sun mode.
- [ ] ⚙ AI → **↓ export everything** (backup of clips, trainer progress, chord table).

---

## C · Blend & play (~20 min) — full pipeline (Saturday)

**0–5 min · seed & blend**
- [ ] Open a saved clip → **⇢ seed mixer** (its genres, key and BPM land in the rail; it becomes the reference).
- [ ] Tab **01 — Visual Mixer**: add one more genre chip, nudge the ratio sliders toward it.
- [ ] **Generate blend ↗** → read the creative direction.
- [ ] Inner tab **Guitar tab** → **Generate** (key + style). Also **Piano / chord chart** → generate.
  - Tip: tab **02 — Guided Workflow** shows these steps as done / current / locked if you lose your place.

**5–12 min · make it yours**
- [ ] Inner tab **Shape trainer** → **My chords** → **+ track** named "<clip> × <genre>".
- [ ] Chord table → **fill 7ths** (or **fill key**) for the current key.
- [ ] Drag table diagrams onto the track in the order the generated chart gave you (drop between blocks; hover left/right of a block to place before/after).
- [ ] Re-voice each block: edit frets (**✎ edit** → type → **✓ save**) or change quality until it sits under your fingers.
- [ ] Piano / chord chart → **⊕ Compose** so guitar + piano run on one clock; play along 2×.

**12–18 min · fills**
- [ ] Loop two adjacent chords (per-card looper on the guitar tab, or just metronome).
- [ ] Gap fill: **▶ play** → copy it → **🔀 different lick** until one lands. Play it clean 5×.
- [ ] Move to the next gap. Two clean fills = done.

**18–20 min · keep it**
- [ ] Worth keeping? Guitar tab / Phrase composer → **export MIDI**.
- [ ] Drag the best 1–2 voicings from the track down to the Chord table.
- [ ] Note in the clip's **notes** field what you blended it with.

---

## Rules of thumb
- Never skip B two days in a row — box 2+ cards (1 / 3 / 7-day intervals) only advance if you show up.
- Explore never records; if you want it counted, do it in quiz.
- One new clip per A session; don't hoard un-transcribed links.
- Export everything weekly; localStorage is the only copy.
